# Sistema Integral de Expansion Retail (SIER)

**Autor:** | Abogado & AI Solutions Architect | LegalTech & Análisis Forense de Datos

Este repositorio contiene herramientas avanzadas de analitica, Machine Learning y modelado financiero aplicadas a la estrategia de expansion fisica para el sector retail.

## Proyectos
1. **Geomarketing y Clustering (Python):** Uso de K-Means para identificar zonas de alto potencial (flujo peatonal, estrato, costos).
2. **Modelo Financiero (CAPEX/ROI):** Evaluacion de rentabilidad de locales.
3. **Agente IA de Negociacion:** Analisis automatico de contratos de arrendamiento.

---
**Tecnologias:** Python, Scikit-Learn, Pandas, Power BI, Machine Learning.
